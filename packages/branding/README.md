# @openmasq/branding — the one home of the brand

<sub>**English** · [Français](#openmasqbranding--lunique-foyer-de-la-marque)</sub>

`branding.json` holds the name, domains, URL scheme and storage keys; `BRAND`,
`brandHost`, `brandUrl`, `brandKey`, `brandHeader` derive every runtime, wire and disk
value from it. Nothing else in the repository spells the brand as a literal — the
`check:brand` gate guards the retired names.

---

# @openmasq/branding — l'unique foyer de la marque

`branding.json` détient le nom, les domaines, le schéma d'URL et les clés de stockage ;
`BRAND`, `brandHost`, `brandUrl`, `brandKey`, `brandHeader` en dérivent toute valeur
d'exécution, de protocole et de disque. Rien d'autre dans le dépôt n'écrit la marque en
littéral — la porte `check:brand` garde les noms retirés.
